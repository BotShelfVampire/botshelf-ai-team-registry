# Writing Draft — Ollama

## How to run
1. Install Ollama and pull a base model you already trust (example: llama3.2).
2. Save the Modelfile above in an empty folder.
3. Run: ollama create botshelf-writing-draft -f Modelfile
4. Run: ollama run botshelf-writing-draft
5. Paste your input (see Example in). Expect the structured output; then stop.

## Example in

```
Notes: announce Build Library stage 1. Free. Local AI. Not replacing marketplace teams. Soft CTA to sell/fork.
Audience: AI builders
```
