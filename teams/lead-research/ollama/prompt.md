# Lead Research — Ollama

## How to run
1. Install Ollama and pull a base model you already trust (example: llama3.2).
2. Save the Modelfile above in an empty folder.
3. Run: ollama create botshelf-lead-research -f Modelfile
4. Run: ollama run botshelf-lead-research
5. Paste your input (see Example in). Expect the structured output; then stop.

## Example in

```
Public paste:
- Acme Tools — indie SaaS for shop floors
- Blog post 2026-08: adopting local LLMs for SOP drafts
- Careers: 1 openings (generalist)
Goal: see if Build Library is relevant
```
