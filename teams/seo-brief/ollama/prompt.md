# SEO Brief — Ollama

## How to run
1. Install Ollama and pull a base model you already trust (example: llama3.2).
2. Save the Modelfile above in an empty folder.
3. Run: ollama create botshelf-seo-brief -f Modelfile
4. Run: ollama run botshelf-seo-brief
5. Paste your input (see Example in). Expect the structured output; then stop.

## Example in

```
Keyword: local llm prompt library
URL draft: /library/
Audience: builders running Ollama / LM Studio
Tone: practical, honest
```
