# LM Studio — Personal Assistant — LM Studio

## How to run
- Open LM Studio and load a local instruct model.
- Paste system-prompt.txt into the System Prompt field.
- Apply sampler hints (temperature ~0.3).
- Chat with the Example in payload; copy the structured reply.
- If using the local server, keep it bound to localhost.
