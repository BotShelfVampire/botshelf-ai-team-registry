# Personal Assistant — Ollama

## How to run
1. Install Ollama and pull a base model you already trust (example: llama3.2).
2. Save the Modelfile above in an empty folder.
3. Run: ollama create botshelf-personal-assistant -f Modelfile
4. Run: ollama run botshelf-personal-assistant
5. Paste your input (see Example in). Expect the structured output; then stop.

## Example in

```
Capture:
- finish Library report
- reply to 2 sellers
- dentist?
- idea: MCP pack v2
Energy: medium. Time: 3h focus.
```
